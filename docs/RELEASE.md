NextGenUp 1.2.0 繁體中文社群版 r4：Mac Apple Silicon、Mac Intel、Windows x64。

- 11 個工具的繁體中文介面、桌面啟動畫面、Mac 選單與主要操作訊息。
- 老照片修復／照片降噪的單張拖曳比對：左原圖、右結果。
- 16 主題離線教學與搜尋；彈窗可點外側空白、Esc 或關閉鈕關閉。
- 給 Codex 的 AGENTS.md 與自動辨識平台的安裝腳本。
- 官方原版與本專案套件 SHA-256 校驗、重複安裝檢查、啟動後 AI／FFmpeg doctor。
- 停用覆蓋中文化的官方自動更新。

使用方法：將 `https://github.com/jacky391977/nextgenup-zh-tw` 貼到客戶本機 Codex，輸入「幫我安裝並啟用」。

Release 中的 ZIP 是安裝腳本所用的中文化套件，需搭配自動下載的官方原版；請勿單獨雙擊其中的引擎。沒有客戶媒體或個人資訊。

各平台 `qa-*.json` 記錄合成圖片 AI 2x 與 FFmpeg 影片 2x 的真實處理測試；未宣稱全部選用大型模型均已測試。GitHub runner 檢查不等於每台客戶電腦已驗證，也不能保證不出現系統安全提示。
